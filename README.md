# 💼 Portfolio & CV en Ligne - Toure Sanga

Ce projet est une application web interactive de type "présentation par slides" (style PowerPoint) conçue pour présenter mon CV, mes compétences, mes expériences et mes projets de manière moderne et dynamique.

## 📖 À propos du projet

Ce portfolio a été développé avec une architecture **Full Stack** séparant le backend (API) et le frontend (Interface utilisateur). Il permet une navigation fluide entre les différentes sections du CV avec des animations (Framer Motion) et une interface responsive (Tailwind CSS).

## 🚀 Fonctionnalités

- **Navigation par slides** : Flèches clavier, swipe sur mobile, et barre de progression.
- **Design moderne** : Thème sombre, animations fluides, et effets visuels.
- **API REST** : Gestion dynamique du contenu via Django Admin.
- **Optimisé pour le recrutement** : Liens directs vers les dépôts GitHub des projets.

## 🛠️ Stack Technique

- **Backend** : Python, Django, Django REST Framework
- **Frontend** : React (Vite), Tailwind CSS, Framer Motion, Lucide Icons
- **Base de données** : SQLite (Développement)
